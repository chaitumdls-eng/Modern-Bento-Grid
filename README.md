# Modern-Bento-Grid

Project Documentation: Modern Bento Dashboard
Project Overview
This project is a modern, responsive front-end dashboard designed to showcase clean UI design principles and core interactive web development techniques. Built using HTML5, CSS Grid, and Vanilla JavaScript, it features a modular "Bento Grid" layout and practical day-to-day utilities.
Key Features
Bento Grid Layout: Structured using modern CSS Grid for a sleek, responsive, and organized user interface.
Theme Toggle System: Implements a light/dark mode switch that saves user preferences using browser localStorage to persist themes across reloads.
Live Weather Integration: Connects to the Open-weather API to fetch and display real-time temperature and location data dynamically.
Task Management System: Allows users to add, track, and manage quick tasks with an interactive state management system.
Technologies Used
HTML5: For semantic and structural layout markup.
CSS3 / CSS Grid: For advanced styling, custom properties, and responsive grid arrangement.
vanilla JavaScript: For application logic, DOM manipulation, asynchronous API requests, and state persistence.
Setup & Running Locally
Clone or download the project repository.
Open the index.html file in any modern web browser to view the dashboard in action.
